# MA均线策略量化回测界面配置规范（最终定稿）

1\. 策略参数配置区（全部开放编辑）

K 线周期下拉选项：周线 / 日线

MA 均线周期：下拉单选，默认值 = 5

买入条件：收盘价 \> MA 均线（固定逻辑，仅周期跟随上方配置）

信号判定日：每周五收盘（固定不变）

成交规则：

买入成交价 = 信号产生后下周一收盘价

卖出成交价 = 信号产生后下周一收盘价

**【非交易日兜底规则】**

信号判定日兜底：若基准周五为非交易日（节假日/休市），自动向前匹配**本周最后一个交易日**作为信号判定日，以当日收盘价计算均线、生成买卖信号。

成交日兜底：若基准下周一为非交易日（节假日/休市），自动向后顺延匹配**首个开盘交易日**，以顺延当日收盘价作为最终买入/卖出成交价。

持仓天数口径：统一按**自然日历天数**计算（开仓成交日至平仓成交日），包含周末、节假日，用于匹配阶梯赎回费率与锁仓冷却期判定。

2\. 份额费率切换（单选框互斥）

☐ A 类份额

☐ C 类份额

面板联动规则

选中 A 类：展示 A 类全部费率输入框，隐藏 C 类配置项

选中 C 类：展示 C 类费率，锁定申购费率为 0，隐藏 A 类管理费与 5 档赎回费率

A 类（全部自定义可编辑）

申购费率 \(%\)：输入框，默认 0\.15

年化管理费 \(%\)：输入框，默认 2\.00

赎回费率档位：

持仓＜7 天：\_\_\_\_ % 默认 1\.50

7 ≤ 持仓＜30 天：\_\_\_\_ % 默认 0\.75

30 ≤ 持仓＜365 天：\_\_\_\_ % 默认 0\.50

365 ≤ 持仓＜730 天：\_\_\_\_ % 默认 0\.25

持仓≥730 天：\_\_\_\_ % 默认 0\.00

C 类（仅服务费 \+ 两档赎回费可编辑）

申购费率：固定 = 0，只读不可修改

年化销售服务费 \(%\)：输入框，默认 0\.50

赎回费率档位：

持仓＜7 天：\_\_\_\_ % 默认 1\.50

7 ≤ 持仓＜30 天：\_\_\_\_ % 默认 0\.75

持仓≥30 天：自动 = 0，只读

3\. 公共回测参数（统一输入框）

初始本金：数值框，默认 10000

锁仓冷却期（买入 N 天内禁止平仓）：数值框，默认 7

买入价格偏离率：默认 \+ 0%

卖出价格偏离率：默认 \- 0%

平仓比例：占初始持仓百分比，默认 100%

回测起止日期选择：日期选择器，默认近3年

## 4\. 前端页面与跳转（与代码同步）

本系统为前后端分离 monorepo，新增两个量化页面，均在主区域内（保留左侧标的侧边栏）。页面间跳转使用 `vue-router`（hash 模式，URL 可分享/刷新保持）。

### 4.1 路由表

| path              | name   | component      | 说明       |
| ----------------- | ------ | -------------- | ---------- |
| `/market`         | market | MarketView     | 行情（默认）|
| `/backtest`       | config | ConfigView     | 策略配置页 |
| `/backtest/result`| result | ResultView     | 回测结果页 |

### 4.2 跳转入口

- 视图顶栏 Tab【行情 | 量化回测】切换行情/量化主区域。
- 配置页【开始回测】：校验通过后写入回测参数 store 并跳转 `/backtest/result`。
- 回测结果页【返回配置】/【重新回测】：跳转 `/backtest`。
- 侧边栏点击标的：跳 `/market?code=...&type=...`，行情页据 query 自动加载；量化页不响应标的点击（仅顶部展示当前标的提示）。

### 4.3 标的来源

文档 1~3 节未列标的字段。**标的复用左侧栏当前选中标的**（与行情页共享选股状态），配置页顶部提示当前标的，无标的时禁止提交并提示「请先在左侧侧边栏选择标的」。

### 4.4 配置页（ConfigView）

按 1~3 节顺序分三区：①策略参数 ②份额费率切换 ③公共回测参数。
固定逻辑（买入条件、信号判定日、成交价规则、兜底规则、持仓天数口径）以只读说明文字呈现，不可编辑；A/C 份额单选互斥并联动显隐对应费率项。

### 4.5 回测结果页（ResultView，只读）

- 指标数字面板：总收益率/年化收益率/最大回撤/夏普比率/交易次数/胜率/平均持仓天数/手续费合计。
- 核心可视化图表（净值曲线 / 回撤曲线 可切换）：
  - 净值曲线：策略净值 vs 基准净值双折线、买卖点 scatter 标注，可开关超额收益柱副图。
  - 回撤曲线：策略/基准回撤 area 折线（y 轴反向、向下为负），标注最大回撤点。
- 交易明细表格：序号/方向/信号日/成交日/成交价/份额/金额/持仓天数/手续费/收益率，置底汇总行，支持导出 CSV / Excel（前端生成，utf-8 BOM 兼容中文）。

### 4.6 数据契约（后端预留）

请求 `POST /api/v1/backtest/run`，体为 `{code, type, config}`；响应为 `{metrics, curve, trades, summary, snapshot}`。后端未落实施时，前端在请求失败给出中文提示。

> 后端回测功能的完整接口契约、引擎算法、复用服务与开发指引见 [`docs/backtest.md`](./backtest.md)。
